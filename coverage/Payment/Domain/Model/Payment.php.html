24/**
25 * Payment Aggregate Root.
26 *
27 * Manages payment lifecycle:
28 * - Create: Initialize payment for an order
29 * - Authorize: Reserve funds (pre-authorization)
30 * - Capture: Complete payment and transfer funds
31 * - Refund: Return funds to customer
32 * - Cancel: Cancel before capture
33 * - Fail: Handle payment failures
34 *
35 * Business Rules:
36 * - Payment amount must match order total
37 * - Status transitions must follow valid state machine
38 * - Gateway transaction ID required after authorization
39 * - Refunds only allowed for captured payments
40 * - Partial refunds supported (up to captured amount)
41 * - Multi-currency support (amount stored in cents)
42 * - Retry Policy:
43 *   - Maximum 3 retry attempts for transient failures
44 *   - Exponential backoff: 1h, 4h, 24h
45 *   - Only retry transient errors (card_declined, insufficient_funds, processing_error)
46 *   - Never retry: expired_card, fraudulent, invalid_card_number
47 */
